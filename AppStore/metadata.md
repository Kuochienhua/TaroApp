## 審核備註（App Review Information → Notes）
This is a tarot card reading app with an immersive, mystical UI experience. The app features:
- Six topic categories (Love, Career, Finance, Health, Spiritual, Free) to guide the user's question
- Four spread types: Daily (1 card), Classic Past/Present/Future (3 cards), Relationship (3 cards), Five-Star (5 cards)
- All 78 tarot cards are bundled locally with multi-dimensional meanings
- An optional on-device AI model (Qwen2.5-1.5B, ~1GB, downloaded once from HuggingFace) for personalized interpretations — the app works fully without it using the built-in local reading engine

The app is fully offline after initial launch, requires no login, collects no user data, and contains no in-app purchases.

To test: tap through the intro → constellation scene → table → write a question → choose a spread → draw cards → view the reading.
