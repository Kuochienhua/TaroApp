# 截圖說明

## 規格
- 尺寸：1320 × 2868 px（6.9 吋 iPhone 16 Pro Max）
- 格式：PNG 或 JPG
- 數量：至少 1 張，建議 5 張

## 截圖步驟（Xcode 模擬器）

1. 在 Xcode 選擇 **iPhone 16 Pro Max** 模擬器
2. 執行 App（⌘R）
3. 在模擬器各頁面按 **⌘S** 儲存截圖（存至桌面）
4. 將截圖依序命名後放入此資料夾

## 建議截圖順序

| 檔名 | 畫面 | 重點 |
|------|------|------|
| 01-intro.png | 啟動動畫（燭光粒子） | 展示沉浸式美學 |
| 02-question.png | 問題頁（情境主題 + 牌陣選擇） | 展示六大主題、四種牌陣 |
| 03-mystic.png | 抽牌前（神秘女祭司動畫） | 展示過場動畫 |
| 04-draw.png | 牌飛出瞬間 | 展示翻牌動畫 |
| 05-reading.png | 解讀頁面（AI 文字解析） | 展示核心功能 |

## 上傳到 App Store Connect

App Store Connect → 你的 App → 1.0 準備提交 → iPhone 截圖 → 拖曳上傳
